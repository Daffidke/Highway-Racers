# Highway-Racers

A classic 2D top-down highway racing and arcade browser game built with modern Vanilla JavaScript and the HTML5 Canvas API.

---

## Overview

**Highway-Racers** is a reflex-driven arcade game where the objective is to survive as long as possible on a busy multi-lane highway. As distance increases, vehicle speeds and traffic density scale up, challenging the player's reaction time, lane maneuvering, and collision avoidance.

---

## Features

* **Continuous Game Loop:** Smooth, 60 FPS rendering and physics state updates powered by `requestAnimationFrame`.
* **Real-Time Collision Detection:** Bounding-box (AABB) collision checks between the player vehicle and dynamic road obstacles.
* **Dynamic Difficulty Scaling:** Traffic accelerates and spawns with higher frequency as the player's score increases.
* **Responsive Controls:** Intuitive keyboard controls (Arrow keys / WASD) for lane-switching, accelerating, and braking.
* **Scoring & State Tracking:** Live HUD score display with game-over state handling and quick restart capability.

---

## Technology Stack

* **Language:** Vanilla JavaScript (ES6+)
* **Graphics & Rendering:** HTML5 Canvas API
* **Styling & Layout:** CSS3
* **Markup:** Clean HTML5 (zero external framework dependencies)
